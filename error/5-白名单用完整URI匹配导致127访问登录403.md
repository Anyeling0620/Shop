# 用 127.0.0.1 访问时登录被网关 403 拦截

## 错误信息

```
POST http://localhost:8081/user/user/login/do_login 403 (Forbidden)
```

只在浏览器访问 `http://127.0.0.1:18004` 时出现；访问 `http://localhost:18004` 时正常。

## 原因

`gateway/src/main/java/com/zhuawa/shop/gateway/filter/AuthFilter.java` 的免登录白名单匹配用的是**完整 URI** 与配置项做字符串比较：

```yaml
auth:
  skip:
    urls: http://localhost:8081/user/user/login/do_login
```

网关收到请求后 `request.getURI()` 的 host 部分跟着 `Host` 头走。前端从 `127.0.0.1:18004` 加载页面时，请求打到 `127.0.0.1:8081`，完整 URI 变成 `http://127.0.0.1:8081/user/user/login/do_login`，与白名单里的 `localhost` 版本不相等，于是登录接口也被要求带 token，直接 403。

## 修复

白名单改成只比较**路径**，忽略 scheme/host/query：

```java
private boolean isSkippedUrl(String path) {
    if (path == null || skipAuthUrls == null) return false;
    for (String raw : skipAuthUrls) {
        if (raw == null || raw.trim().isEmpty()) continue;
        String candidate = raw.trim();
        int scheme = candidate.indexOf("://");
        if (scheme >= 0) {
            int slash = candidate.indexOf('/', scheme + 3);
            candidate = slash < 0 ? "/" : candidate.substring(slash);
        }
        int query = candidate.indexOf('?');
        if (query >= 0) candidate = candidate.substring(0, query);
        if (candidate.equals(path)) return true;
    }
    return false;
}
```

调用处传 `request.getURI().getPath()`。
