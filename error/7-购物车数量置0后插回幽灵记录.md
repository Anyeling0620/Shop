# 购物车数量改为 0 后仍残留一条记录

## 错误信息

商品数量改为 0 后，`GET /order/cart/list` 仍返回该商品，`count` 为 0；页面上出现一条价格为 0 的空行。

## 原因

`order-service/src/main/java/com/zhuawa/shop/order/service/CartService.java` 的 `setCount` 里：

```java
if (count <= 0) {
    cartItemDao.delete(cartItem);
}
cartItemDao.insert(cartItem);   // 没有 return，删除后又被插回
```

删除后没有提前返回，接着执行了插入，把 `count=0` 的记录又写回去。

## 修复

删除后直接返回：

```java
if (count <= 0) {
    cartItemDao.delete(cartItem);
    return;
}
```

验证：对同一 `goodsId` 调 `set 0` 后，`/order/cart/list` 返回空数组。
