# 跨域下浏览器读不到 zhuawa-shop-token 响应头

## 错误信息

登录接口 `POST /user/user/login/do_login` 返回 200、`code:0`，但浏览器里：

```js
response.headers.get('zhuawa-shop-token')  // null
```

前端因此拿不到 JWT，后续请求全部 401/403。

## 原因

CORS 规范下，浏览器 JS 只能读取 CORS-safelisted 的几个响应头（`Cache-Control`、`Content-Type`、`Expires` 等）。自定义响应头即使网关已经发送，跨域时对 JS 依然不可见。

`gateway/src/main/resources/application.yml` 的 `globalcors` 里只配了 `allowedHeaders`（控制请求头），没配 `exposedHeaders`（控制响应头可见性）。curl 直接看响应头是正常的，所以这个坑只在浏览器里出现。

## 修复

网关 CORS 配置补上 `exposedHeaders`：

```yaml
            exposedHeaders:
              - "zhuawa-shop-token"
```

改完重启网关，浏览器 `response.headers.get('zhuawa-shop-token')` 即可拿到。
