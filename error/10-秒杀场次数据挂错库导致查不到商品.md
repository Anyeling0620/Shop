# 秒杀场次配置后列表查不到商品

## 错误信息

`GET /seckill/seckill/list` 返回的场次里 `goodsId` 为 `null`，前端 `GoodsInfo` 为空，秒杀页不显示商品。

## 原因

秒杀服务读的是 **seckill 库自己的 `goods` 表**，不是 goods 库的 `goods` 表。两库的 `goods.id` 是各自独立的自增序列，同一个数字在两边指向完全不同的商品，甚至一边根本不存在。

最初把场次数据建在 goods 库里真实存在的商品 id 上，seckill 库中查不到对应行，关联结果为空。

## 修复

场次数据必须落在 seckill 库存在的商品 id 上。示例脚本 `sql/seckill_demo_session.sql` 先在 seckill 库造 id 999/1000 两条商品，再挂场次：

```sql
insert into seckill.goods(id, name, image, price, ...) values
  (999, '华为Mate40Pro ...', '/img/xxx.jpg', 3999.00, ...);

insert into seckill.seckill_goods(id, goods_id, session_id, seckill_price, stock_count, ...) values
  (1, 999, 1, 3999.00, 50, ...);
```

排查口诀：秒杀页商品为空，先确认 `seckill.goods` 里有这个 id。
